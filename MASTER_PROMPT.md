# Master prompt — Brand Motion Graphics Kit

Before editing, request an uploaded brand guideline or complete equivalent details: approved logo variants, hex colors, typefaces and font rights, voice, CTA, website, languages, safe-area rules, prohibited treatments, target platforms, aspect ratios, duration and desired motion style. Ask for source footage if an overlay must be positioned around people/products. Never infer brand permission from downloaded references.

If guidelines are missing, ask for the brand website and have the operator approve your extracted brief. Do not silently reuse this template's sample palette. Ask whether the operator wants an ending, lower third, title or a complete sequence. This repository implements endings and overlays; additional components must be implemented and verified before you claim they exist.

Read the existing brand.json and source. Replace all sample brand/CTA/URL values. Use approved local assets and retain third-party notices. Keep the old project and its assets outside this public repository. Use actual font loading and wait for it before rendering when custom fonts are supplied.

Keep deterministic frame-based timing. Adapt layout to each aspect ratio; do not merely crop a vertical render. Position overlays clear of faces, hands, garments and platform UI. Brand marks and readable copy belong in vector/text layers, not generated footage. Validate long brand names, multiline headlines and URL width. Shorten copy with the operator rather than shrinking it unreadably.

For additional generated media, ask for the creative brief, references, provider, budget and approval first. Preserve subject/product invariants, inspect actual footage and do not spend generation credits merely to repair an editing error. Distinguish a real camera angle from a digital zoom. Use original or licensed audio only.

Run the type check, render each requested ratio, inspect frames at entrances/holds/exits and both sides of every cut, and play the full result at normal speed. Follow QUALITY_CHECKS.md. If only stills or silent footage were checked, say so. Produce a review export first unless publication is already explicitly authorized. Preserve accurate limits; never call a technically rendered ad a proven conversion winner.
## AI host and model choice

Use a tool-capable AI host with repository/file access, a browser, connected email, and Apollo or Lusha. This repository does not install or authenticate those services automatically. ChatGPT Work/Codex and Claude environments differ; inspect the actual tools available before running.

Suggested starting point: GPT-6.1 Sol at Light/low or Medium effort for routine research and CRM work; GPT-6 Astra for difficult setup, reasoning and repairs. A newer capable model is fine if available. These are recommendations, not a benchmark or a promise of compatibility. Claude users can use a current tool-capable Claude model; OpenAI model names are not Claude options.

Model reference checked 2026-11-10: [OpenAI model guidance](https://learn.chatgpt.com/docs/models?surface=web). Recheck your model picker and tool access rather than hardcoding future model names. Model subscriptions, provider credits and cloud compute may cost money.
